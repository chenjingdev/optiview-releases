# OptiView

지금 보고 있는 터미널의 Claude Code·Codex 답을 옆의 작은 읽기 창에 보여 주는 맥 메뉴 막대 앱입니다. cmux와 Orca에서는 클릭한 칸의 대화를 따라가고, 그 밖의 터미널에서는 마지막으로 질문한 세션을 보여 줍니다.

이 저장소에는 내려받을 앱만 올립니다. 소스 코드는 비공개입니다.

## 설치

1. [최신 릴리스](https://github.com/chenjingdev/optiview-releases/releases/latest)에서 `OptiView-<판>-arm64.dmg`를 받습니다.
2. DMG를 열고 OptiView를 응용 프로그램 폴더로 끌어 넣습니다.
3. OptiView를 켜면 메뉴 막대에 아이콘이 생깁니다. Dock에는 아이콘이 없습니다.

- Apple Silicon 맥, macOS 13 이상에서 돕니다.
- Apple 공증을 받은 앱이라 경고 없이 열립니다.

## 업데이트

앱이 켜질 때와 6시간마다 이 저장소의 새 릴리스를 확인합니다. 새 판을 받아 두면 메뉴 막대 메뉴에 "업데이트하고 다시 시작"이 생기고, 그냥 두어도 앱을 끌 때 설치됩니다.

## 개인정보

답을 따로 저장하지 않고 에이전트의 기록 파일(`~/.claude`, `~/.codex`)을 이 맥 안에서 읽기만 합니다. 업데이트 확인으로 GitHub에 접속하는 것 말고는 밖으로 보내는 데이터가 없습니다.
